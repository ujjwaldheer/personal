⑤ Prompt / Context Augmentation
Retrieved text is placed into the context sent to the LLM.
Notice: The LLM is not receiving the vector embeddings themselves. It receives the retrieved text/context along with instructions and the user's question.
⑥ LLM Generation
The LLM receives the augmented context and generates a response.

The mental model you should take away from this simulation.
Without RAG
User question → LLM → Answer
The LLM primarily relies on its pretrained knowledge and whatever context the application provides.
With RAG
User question → Retrieve relevant knowledge → LLM → Answer
RAG gives the LLM relevant external information at inference time.
